LOVERTORN RECORDS

Authorized music and video publishing workflows.

LOVERTORN is an internal publishing and catalog-management tool used by LOVERTORN RECORDS to authenticate official social accounts, verify existing catalog entries, prevent duplicate uploads, and manage authorized music-video publishing workflows.

TikTok integration

The TikTok integration uses Login Kit and Content Posting API capabilities only for accounts that have explicitly authorized LOVERTORN. The integration is used to identify the authorized account, review existing public video metadata, upload authorized content, and publish content when the account grants the required permissions.

LOVERTORN does not request or store TikTok account passwords.

Service status

LOVERTORN is currently an internal operational tool for LOVERTORN RECORDS. It is not offered as a public consumer software service.
